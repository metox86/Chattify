## 🌟 Key Features

- 📞 **Voice & Video Calls:** Crystal-clear real-time voice and video communication powered by WebRTC.
- 📁 **File & Media Sharing:** Fast and secure upload/download functionality for images, documents, and attachments.
- 💬 **Direct Messaging (DMs):** One-on-one instant messaging with low latency.
- 👥 **Group Channels & Chats:** Create, manage, and participate in multi-user group conversations effortlessly.
- 🎨 **Modern UI/UX:** Clean, responsive, and intuitive interface designed with precision in Figma.

## 🚀 Getting Started

Follow these steps to set up Chattify locally on your machine.

### **Prerequisites**
- [Node.js](https://nodejs.org/) (v18 or higher)
- `npm` or `pnpm` / `yarn`

### **Installation**

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/metox86/chattify.git](https://github.com/metox86/chattify.git)
   cd Chattify
   ```
2. **Install dependencies:**
  ```bash
# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
  ```
3. **:**
  Create a .env file in both frontend and backend directories using the provided .env.example templates.
4. **Run the frontend application and backend server**:
  ```bash
 # Start backend server
cd backend
npm run dev

# Start frontend client
cd frontend
npm run dev
  ```
